Small-Cap Quality Portfolio¶

FINA 6334 — Empirical Methods¶

Quality Definition: ROA (profitability) + Low Accruals (earnings quality) + Low Leverage (safety)
Framework: Asness, Frazzini & Pedersen (2014)
Universe: U.S. common stocks, NYSE 20th–50th ME percentile, price ≥ $5
Sample: January 2000 – present
Rebalancing: Quarterly (end of each calendar quarter), 200-stock cap
Benchmark: IWM (iShares Russell 2000 ETF)
Weighting: Equal-weighted

Project Overview¶

This project constructs and evaluates a small-cap quality equity portfolio using institutional-grade data from CRSP and Compustat (via WRDS).

Grounded in the Asness, Frazzini & Pedersen (2014) quality-minus-junk framework, stocks are scored on three dimensions - gross profitability, low accruals, and low leverage and ranked cross-sectionally each quarter. The portfolio selects the top quality quintile from the NYSE 20th–50th market cap percentile universe, equal-weighted across up to 200 stocks, with a $5 minimum price filter and look-ahead bias correction built in.

Performance is benchmarked against the IWM (iShares Russell 2000 ETF) across a 24-year sample period (2001–2024), with full Fama-French factor attribution, stress period analysis across major market crises, and average quarterly turnover of 23.2%.

Key topics: Factor investing, Quality signals, Portfolio construction, Fama-French attribution, Drawdown analysis¶

comp['gvkey']    = comp['gvkey'].astype(str)
comp['datadate'] = pd.to_datetime(comp['datadate'], errors='coerce')
 
# Signal 1: Gross Profitability = GP / AT  (profitability)
if 'gp' in comp.columns:
    comp['gprof'] = comp['gp'] / comp['at']
else:
    comp['gprof'] = (comp['sale'] - comp['cogs']) / comp['at']
 
# Signal 2: Low Accruals = (OANCF - NI) / AT  (earnings quality)
comp['accruals'] = (comp['oancf'] - comp['ni']) / comp['at']
 
# Signal 3: Leverage = DLTT / AT  (safety — will invert when ranking)
comp['lev'] = comp['dltt'] / comp['at']
 
# 40% of small-cap firms have negative payout (equity issuance).
# This pushes high-growth firms into "junk" and mature/declining
# firms into "quality", reversing the quality-return relationship.
 
comp = comp.replace([np.inf, -np.inf], np.nan)
comp = comp.dropna(subset=['gprof', 'lev', 'at'])
comp = comp[comp['at'] > 0]
 
# June look-ahead bias correction
comp['avail_date'] = comp['datadate'].apply(
    lambda d: pd.Timestamp(d.year + 1, 7, 1)
) + pd.offsets.MonthEnd(0)
 
# merge with CCM using link dates, not just gvkey
comp_linked = comp.merge(ccm, on='gvkey', how='inner')
comp_linked = comp_linked[
    (comp_linked['avail_date'] >= comp_linked['linkdt']) &
    (comp_linked['avail_date'] <= comp_linked['linkenddt'].fillna(pd.Timestamp('today')))
]
 
acct = (
    comp_linked[['permno', 'avail_date', 'gprof', 'accruals', 'lev']]
    .rename(columns={'avail_date': 'date'})
    .sort_values(['permno', 'date'])
    .drop_duplicates(['permno', 'date'], keep='last')
)

9. Quality Score & Quintile Assignment (Quarterly Rebalancing)¶

Score = ROA percentile rank + Gross Profitability percentile rank + Leverage percentile rank (inverted) Framework: Asness, Frazzini & Pedersen (2014) — profitability (2 signals) + safety (1 signal)

In [11]:
df['month']   = df['date'].dt.month
df['qtr_end'] = df['month'].isin([3, 6, 9, 12])
 
# Cross-sectional ranks
df['gprof_rank']    = df.groupby('date')['gprof'].rank(pct=True)            # higher GP = better
df['accruals_rank'] = df.groupby('date')['accruals'].rank(pct=True)          # more cash-based = better
df['lev_rank']      = df.groupby('date')['lev'].rank(pct=True, ascending=False)  # lower leverage = better
 
# Composite: 30% profitability (gprof) + 40% earnings quality (accruals) + 30% safety (leverage)
df['quality'] = (
    0.30 * df['gprof_rank'] +
    0.40 * df['accruals_rank'] +
    0.30 * df['lev_rank']
)
df = df.dropna(subset=['quality'])
 
# Quintiles at quarter-ends, forward-filled
df['quintile'] = np.nan
qtr_mask = df['qtr_end']
df.loc[qtr_mask, 'quintile'] = (
    df[qtr_mask]
    .groupby('date')['quality']
    .transform(lambda x: pd.qcut(x.rank(method='first'), 5, labels=False))
)
 
df = df.sort_values(['permno', 'date'])
df['quintile'] = df.groupby('permno')['quintile'].ffill()
df = df.dropna(subset=['quintile'])
df['quintile'] = df['quintile'].astype(int)
 
print("Quintile counts (full sample):")
print(df['quintile'].value_counts().sort_index())

def portfolio_stats(ex, tot, factors):
    """Compute annualized performance metrics."""
    idx = ex.dropna().index.intersection(factors.dropna().index)
    ex, tot, factors = ex[idx], tot[idx], factors.loc[idx]

    ann_ret = ex.mean() * 12
    ann_std = ex.std() * np.sqrt(12)

    cum = (1 + tot).cumprod()
    max_dd = ((cum - cum.cummax()) / cum.cummax()).min()

    reg = sm.OLS(ex, sm.add_constant(factors)).fit(
        cov_type='HAC', cov_kwds={'maxlags': 6}
    )

    return {
        'Ann. Mean Excess Return': f"{ann_ret * 100:.2f}%",
        'Ann. Std Dev':            f"{ann_std * 100:.2f}%",
        'Sharpe Ratio':            f"{ann_ret / ann_std:.3f}",
        'Max Drawdown':            f"{max_dd * 100:.2f}%",
        '3-Factor Alpha (ann.)':   f"{reg.params.iloc[0] * 12 * 100:.2f}%",
        't-stat on Alpha':         f"{reg.tvalues.iloc[0]:.2f}",
    }

top_sorted = top_q.sort_values('date')
q_dates = (
    top_sorted
    .groupby(top_sorted['date'].dt.to_period('Q'))['date']
    .max()
    .values
)

turnover = []
prev = set()
for dt in q_dates:
    curr = set(top_sorted[top_sorted['date'] == dt]['permno'].values)
    if prev:
        sold    = len(prev - curr)
        bought  = len(curr - prev)
        avg_n   = (len(prev) + len(curr)) / 2
        turnover.append((sold + bought) / (2 * avg_n) if avg_n else 0)
    prev = curr

print(f"Avg quarterly turnover: {np.mean(turnover) * 100:.1f}%")
print(f"Rebalancing periods:    {len(turnover)}")
